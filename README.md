# صفحة برنامج IELTS

صفحة تسجيل عربية باتجاه RTL مبنية باستخدام React وVite، مع حفظ طلبات التسجيل الأولية في جدول `inquiries` على Supabase.

## التشغيل محليًا

1. ثبّت الاعتماديات باستخدام `npm install`.
2. أنشئ ملف `.env` من `.env.example`، ثم أدخل عنوان مشروع Supabase ومفتاح `anon` العام في `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY`.
3. طبّق ملفات SQL داخل مجلد `migrations` على قاعدة بيانات Supabase، بالترتيب.
4. شغّل `npm run dev` وافتح العنوان الذي يظهر في الطرفية.

استخدم مفتاح Supabase العام `anon` فقط في تطبيق المتصفح. لا تضع مفتاح `service_role` في متغيرات `VITE_*` أو في ملفات الواجهة.

سياسة قاعدة البيانات تسمح بإرسال طلب التسجيل، ولا تسمح للزوار بقراءة بيانات الطلبات أو تعديلها أو حذفها. يتطلب الوصول الإداري إعداد مصادقة وسياسات منفصلة.

## أوامر المشروع

- `npm run dev` — تشغيل خادم التطوير.
- `npm run build` — إنشاء نسخة الإنتاج داخل `dist`.
- `npm run preview` — معاينة نسخة الإنتاج محليًا.
